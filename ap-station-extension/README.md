# AP บันทึกเวลาออกสถานี — Chrome Extension (ช่วง 1)

## ติดตั้ง
1. แตกไฟล์ zip ไว้ในโฟลเดอร์ถาวร (ห้ามลบหลังติดตั้ง)
2. เปิด Chrome ไปที่ `chrome://extensions`
3. เปิด **Developer mode** (มุมขวาบน)
4. กด **Load unpacked** แล้วเลือกโฟลเดอร์ `ap-station-extension`
5. ปักหมุดไอคอน แล้วคลิกเพื่อเปิดหน้าหลัก

## ใช้งานช่วง 1
1. **สถานี** – วาด polygon ทั้ง 3 สถานี (QMB บ้านบึง, Mentor เขาตะแบก, สนามบิน Expeditors)
   - วางพิกัดจาก Google Maps แล้วกด "ไปที่พิกัด" → กด "วาด polygon" → คลิกมุมทีละจุด → บันทึก
   - ลากจุดเพื่อปรับ คลิกขวาที่จุดเพื่อลบ
   - ช่อง "ทดสอบ" ใช้เช็คว่าพิกัดหนึ่งอยู่ในสถานีไหน
2. **นำเข้าไฟล์** – ลากไฟล์ Truck Detail (.csv / .xlsx) มาวาง ตรวจคำเตือน แล้วกดนำเข้า
3. **เที่ยวงาน** – ดูเที่ยวรายวัน คัดลอก HAWB ได้
4. **ตั้งค่า** – ใส่ Token GPS (ใช้ช่วง 2) และส่งออกไฟล์สำรองสถานี + เส้นทาง

## ข้อมูล
- เก็บในเครื่องนี้เท่านั้น (chrome.storage.local) ไม่ส่งออกนอกเครื่อง
- ไม่อ่านคอลัมน์เลขบัตรประชาชนและเบอร์โทรจากไฟล์
- ถอนการติดตั้ง Extension = ข้อมูลหาย ควรส่งออกไฟล์สำรองหลังวาด polygon เสร็จ

## ช่วง 2 — ดึง GPS + ตรวจจับเข้า-ออก (v0.2.0)
- ตั้งค่า → ใส่ Token GPS (Base URL ใช้ค่าเริ่มต้นได้) → **บันทึก** (Chrome จะขอสิทธิ์เข้าถึงโดเมน) → ใส่ทะเบียนทดสอบ → **ทดสอบเชื่อมต่อ**
- background ดึงพิกัดทุก N วินาที (ขั้นต่ำ 30) เฉพาะเที่ยวที่ยังไม่เสร็จใน 2 วันล่าสุด จับคู่รถด้วยทะเบียน
- สถานะเดิน: รอขึ้นงาน → อยู่จุดขึ้นงาน → รอกรอกขึ้นงาน → อยู่จุดส่งงาน → รอกรอกส่งงาน (ต้องเจอผลตรงกัน 2 รอบติดกันถึงนับ)
- แท็บเที่ยวงานมีคอลัมน์ "เวลา GPS" ปุ่ม "ดึง GPS ตอนนี้" และคอลัมน์ Waiting Time (นับจากเข้าจุดรับ รอฟรี 3 ชม. ส่วนเกินปัดตามกติกา คิด 30 บาท/ชม. ปรับได้ในตั้งค่า)

## ยังไม่มีในช่วงนี้
- การ์ดงานรอกรอก แจ้งเตือน ส่งออก Truck Detail พร้อมเวลา (ช่วง 3)

## ซิงก์ข้อมูลทีม (Supabase)
1. สร้างโปรเจกต์ที่ supabase.com แล้วรันไฟล์ `supabase-setup.sql` ใน SQL Editor
2. ตั้งค่า → ซิงก์ข้อมูลทีม: ใส่ Project URL และ anon key (Project Settings → API) แล้วกด **บันทึก** (Chrome จะขอสิทธิ์โดเมน)
3. เปิดช่อง "เครื่องนี้เป็นเครื่องดึง GPS" **เพียง 1 เครื่อง** เครื่องอื่นปิดไว้ (เห็นตำแหน่ง/ETA จากเครื่องดึง GPS)
4. เครื่องใหม่ที่เข้าร่วม: ตั้งค่าซิงก์ก่อนนำเข้าไฟล์ ข้อมูลกลางจะมาแทนข้อมูลในเครื่อง นำเข้าไฟล์ Truck Detail ที่เครื่องเดียว
- ทุกคนดู/แก้ได้ (กรอกแล้ว, แก้เวลา, วาด polygon, เส้นทาง) ถ้าแก้เที่ยวเดียวกันพร้อมกัน คนที่ส่งก่อนชนะ อีกคนจะได้ค่าใหม่ในรอบถัดไป
- ใครมี URL + anon key เข้าถึงข้อมูลได้ทั้งหมด (มีชื่อคนขับ) ใช้ภายในทีมเท่านั้น
- Token GPS ไม่ถูกซิงก์ ต้องใส่เฉพาะเครื่องที่ดึง GPS

## ดึง GPS บนคลาวด์ (ไม่ต้องเปิดเครื่องค้าง)
ดู `CLOUD-SETUP.md` · ฟังก์ชันอยู่ที่ `supabase/functions/gps-poll/index.ts` ตั้งเวลาด้วย `supabase-cron.sql`

## เก็บข้อมูลรายวัน + ส่งออก Excel
- ระบบเก็บเที่ยวของทุกวันไว้ ไม่ลบอัตโนมัติ (ลบได้เฉพาะเมื่อกดลบเอง) เลือกดูย้อนหลังได้ที่ช่อง "วันที่มีข้อมูล" ในแท็บเที่ยวงาน
- ปุ่ม **ส่งออก Excel** เลือกช่วงวันที่ → ไฟล์ .xlsx 3 ชีต: รายเที่ยว (เวลา GPS เข้า/ออก, Waiting Time, เงิน), รายการ HAWB, สรุปรายวัน

## เครื่องแม่ / เครื่องที่เข้าร่วม
- **เครื่องแม่** (มีข้อมูลต้นฉบับ): ตั้งค่า → ซิงก์ข้อมูลทีม → "ตั้งเครื่องแม่/เครื่องที่เข้าร่วม" → **ตั้งเครื่องนี้เป็นเครื่องแม่** (ทำครั้งเดียว ข้อมูลกลางจะเหมือนเครื่องนี้ทุกอย่าง รวม polygon สถานี) ต้องทำก่อนเปิดตัวดึง GPS บนคลาวด์ เพราะคลาวด์อ่าน polygon จากข้อมูลกลาง
- **เครื่องที่เข้าร่วม**: ใส่ Project URL + key แล้วกด **ใช้ข้อมูลของกลางแทนเครื่องนี้** จะเห็นเที่ยว สถานี เส้นทางเหมือนเครื่องแม่
- เครื่องใหม่จะไม่ส่งสถานีเปล่า/เส้นทางตั้งต้นขึ้นไปทับข้อมูลของเครื่องแม่
