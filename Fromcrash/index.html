    ยังไม่มีหมวดหมู่ — เพิ่มที่นี่เพื่อใช้ในฟอร์มเงินสดย่อย/ขออนุมัติ

    🔔 แจ้งเตือน Telegram

    1. เปิดแชทกับ @BotFather ใน Telegram → พิมพ์ /newbot → ตั้งชื่อ Bot → จะได้ Bot Token
    2. เปิดแชทกับ @userinfobot เพื่อดู Chat ID ของคุณ (หรือ Chat ID ของกลุ่มที่อยากให้แจ้งเตือน)
    3. เพิ่ม Bot เข้ากลุ่ม (ถ้าจะแจ้งเตือนในกลุ่ม) แล้วส่งข้อความในกลุ่มสักครั้งก่อน เพื่อให้ Bot คุยกับกลุ่มได้
    ⚠️ ข้อควรระวัง: ค่านี้เก็บในเบราว์เซอร์นี้เท่านั้น (ไม่ sync ข้ามเครื่อง) และ Bot Token จะถูกเรียกใช้ตรงจากหน้าเว็บ ผู้ที่เข้าถึงเว็บนี้และเปิด developer tools อาจเห็น Token ได้
